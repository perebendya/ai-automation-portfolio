How I automated a moderation report

At OBRIO, the moderation system sent an alert to Slack whenever it spotted a possible violation. Every Friday a manager read through several channels and moderator replies, removed duplicates and wrote up the violations and false alarms by hand.

I built an n8n workflow that reads seven alert formats. My code merges duplicates and counts cases. Claude drafts the report from the moderators’ comments.

≈ 2 hours

of manual work saved each week, by my estimate

On Friday the manager had a draft ready to approve. It showed where the system had raised a false alarm and which cases still needed a closer look.

How I handled alerts with no reaction

The manager told me they also checked messages nobody had reacted to. I added a separate Claude call to read those messages or audio transcripts and flag possible false alarms for review. If Claude was unavailable, the manager still received the counts and the original comments.

To respect OBRIO’s policy, I recreated the workflow with fictional messages. Each sample week includes a saved local model draft. Changing a reaction updates the counts and hides the saved draft until the original data is restored.

Download and run the demo in n8n

Download the n8n workflow (.json)

Download the workflow, select Import from File in n8n, then Execute workflow. Open Review report for the four sections. The default run works offline with fictional messages.

In Fictional messages, select followup for the second week or local-llm to draft a summary with Ollama. For that option, serve qwen2.5:0.5b locally and set the HTTP node address if n8n runs in a container.

Завантаж файл процесу. У n8n вибери Import from File, а потім Execute workflow. Відкрий вузол Review report, щоб побачити чотири розділи звіту. За замовчуванням процес працює офлайн на тестових повідомленнях.

У вузлі Fictional messages вибери followup для другого тижня або local-llm для підсумку від Ollama. Для цього запусти qwen2.5:0.5b локально. Якщо n8n працює в контейнері, вкажи доступну з нього адресу моделі в HTTP-вузлі.
