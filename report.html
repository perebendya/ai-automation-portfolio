How the original workflow worked

The original workflow read Slack alerts, reactions and replies. JavaScript calculated the counts. Claude summarized moderator notes and checked unmarked text and audio alerts for possible false positives.

Here, each sample week includes a saved local model draft. Changing a reaction updates the counts and hides the saved draft until the original data is restored.

Run it in n8n

Download the workflow, select Import from File in n8n, then Execute workflow. Open Review report for the four sections. The default run works offline with fictional messages.

In Fictional messages, select followup for the second week or local-llm to draft a summary with Ollama. For that option, serve qwen2.5:0.5b locally and set the HTTP node address if n8n runs in a container.
