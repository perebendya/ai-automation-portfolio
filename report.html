How this relates to the original workflow

The original read Slack alerts, reactions and replies. JavaScript calculated counts for four sections. Claude summarized moderator notes and separately reviewed unmarked text and audio alerts for possible false positives.

This browser demo shows the offline report using sample messages and moderator notes. Unmarked items stay open for review. Each original sample week also includes a saved local model draft. Changing a reaction updates the counts and clears that draft.

Run it in n8n

Download the workflow, select Import from File in n8n, then Execute workflow. Open Review report for the four sections. The default run works without accounts or keys for Slack or a model.

In Fictional messages, select followup for the second week or local-llm to draft a summary of moderator notes with Ollama. For that option, serve qwen2.5:0.5b locally and set the HTTP node address if n8n runs in a container.
