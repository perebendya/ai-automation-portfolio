Run it inside n8n

Download the JSON above. In an empty n8n workflow choose ⋯ → Import from File, then Execute workflow. Open Review report to inspect the result. The default run uses the built-in fictional messages and works without credentials.

In Fictional messages, change the week to followup for the second inbox. For a fresh generative draft on self-hosted n8n, run Ollama on the same machine with ollama run qwen2.5:0.5b and change the mode to local-llm. With containers, point Draft with Ollama to your Ollama service. The workflow keeps the counts and source excerpts if the model is offline.

The browser runs the same counting and extractive-summary code as the n8n workflow. The two original inboxes also include a saved model response from an actual local n8n run. Editing an inbox recalculates the report and shows excerpts from the new messages.
